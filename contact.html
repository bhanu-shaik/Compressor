Contact

Last updated: 27 September 2026

This site is entirely static: there is no server-side code and no contact form, because a form that actually delivered messages would need exactly the kind of backend this site avoids. Instead, the link below opens your own email app with the address and subject already filled in. Nothing is transmitted until you press send in your mail program.

Email us

Open an email

The address is hello@example.com, a placeholder that must be replaced with a monitored mailbox before publishing. See the README for the exact location to change.

What to include

Reports are far more useful with a few details attached:

Browser
For example: Firefox 141 on Windows 11, or Safari 18 on iPhone.
What you did
The steps that led to the problem, starting from opening the page.
What happened
The message you saw, and what you expected instead.
About the file
Format, roughly how large it is, and its pixel dimensions. Please do not attach the image itself unless you specifically want to.

Please do not send

There is no need to send us images, and we would rather you did not. We cannot help with recovering or re-editing a file: your originals never leave your device, and the compressed file is produced on your device too. If a result looks wrong, adjusting the quality, target size or output format and compressing again is the fix.

Privacy questions

If your question is about what this site does with your data, the Privacy Policy already spells it out. If something in it does not match what you observed, please say so — that is a bug in the policy or in the code, and we would rather fix it than defend it.

Response time

This is a small project maintained in spare time, so replies may take a few days. Bug reports that name a browser and a file size are the most likely to get a quick answer.
