      What is an image compressor?

      An image compressor makes an image file smaller while keeping it useful. A photo taken on a modern phone can easily be 4 MB or more, and a screenshot of a text document might be a few hundred kilobytes. Much of that size is detail the file does not need in order to look the way you want it to.

      Compressing rewrites the image with a more compact representation. For JPG and WebP that means storing slightly simplified detail — called lossy compression. For PNG it usually means reducing the number of distinct colours in the image, which is why a screenshot can often shrink by 80% or more while a detailed photo shrinks by less.

      The compressor on this page does that work on your own device, so you can compress a photo before you attach it to an email, upload it to a form with a strict size limit, or publish it on a page you want to load quickly.

      Why compress images?

      • Smaller files

        Fewer kilobytes means less waiting — when uploading an email attachment, a portfolio or a folder of product photos.

      • Faster website loading

        Images are usually the heaviest part of a page. Every kilobytes you remove shortens load times, especially on mobile connections.

      • Easier sharing

        Many services cap attachment size. A 2.4 MB photo that becomes 640 KB passes limits that would otherwise reject it.

      • Reduced storage

        Across a large photo library, shrinking each file frees up meaningful space on your device, your backup drive or your hosting plan.

      Supported formats

      JPG (JPEG)
      The standard format for photographs. It has no transparency, and it offers the most flexible quality control, which makes it the best choice for photos, scans and anything with gradients.
      PNG
      The standard format for graphics, logos, screenshots and anything that needs sharp edges or a transparent background. A quality slider does not apply to PNG, so this tool reduces PNG size by cutting the number of colours while keeping transparency intact. Converting a transparent PNG to JPG removes the transparency, so you will be warned first.
      WebP
      A modern format that usually beats JPG on size at the same perceived quality, and unlike JPG it supports transparency. It is supported by all current versions of Chrome, Edge, Firefox and Safari.

      You can keep the original format or convert between the three. If you are unsure, keeping the original format is the safest choice.

      How to compress an image

      1. Add your image

        Drag a JPG, PNG or WebP file onto the upload area at the top of this page, or press Choose Image to pick one. You can select several files at once.

      2. Choose your settings

        Set the compression quality, pick an output format, and — if a portal or platform gives you a strict limit — choose a target file size instead of a fixed quality.

      3. Compress and compare

        Press Compress Image. The result, the new file size and the percentage saved appear next to the original so you can check the quality before you use it.

      4. Download

        Save the compressed file, or use Download All to get every image in a single ZIP archive built in your browser.

      Frequently asked questions

      Is this image compressor free?

      Yes. There is no account, no trial and no watermark. The tool runs entirely in your browser, so there is no server cost to pass on.

      Are my images uploaded?

      No. Your browser reads the file from your device, the compression code runs on your device, and the compressed result is handed straight back to you. This site contains no code that sends your images anywhere, and the Privacy Policy explains the details.

      What image formats are supported?

      JPG/JPEG, PNG and WebP, both as the input format and as the output format. Other file types are rejected with a clear message.

      Does image compression reduce quality?

      It can, and to a degree you choose. JPG and WebP compression is lossy: the higher the quality setting, the closer the result is to the original. The before-and-after previews let you compare them yourself. PNG compression on this tool reduces the number of colours, which suits screenshots and graphics and is usually a poor trade for detailed photographs.

      Can I compress JPG images?

      Yes. JPG is the best-supported format here: set the quality slider, or choose a target file size and the quality is adjusted for you.

      Can I compress PNG images?

      Yes. Because a PNG quality slider behaves nothing like a JPG one, this tool shrinks PNGs by reducing the colour palette and by switching to a smaller greyscale depth where the image allows it. Transparency is preserved. If your PNG is a detailed photograph, converting it to JPG or WebP usually gives a much smaller file.

      Can I compress WebP images?

      Yes. WebP can be compressed to WebP, and it can be converted to JPG or PNG if a service you need to upload to does not accept WebP.

      Can I compress multiple images?

      Yes. Select or drop several files at once. They are processed one after another, each one can be downloaded on its own, and Download All packages the results into a ZIP file created in your browser.

      Will the result be exactly the size I asked for?

      No. A target size is a goal, not a guarantee. The tool searches for the highest quality that fits under the target. If reaching it would mean visibly damaging the image, it stops and tells you instead, and suggests a larger target or smaller dimensions.

      Are large images resized automatically?

      No. Dimensions are only changed if you pick a limit in the Resize Large Images menu. Very large images are flagged with a warning, because processing them uses a lot of your device's memory.

      Does it work on mobile?

      Yes. The layout adapts to phone screens, the upload button is large enough to tap comfortably, and the compression runs on your phone's own processor. Processing a very large image on an older phone can take a few seconds.
