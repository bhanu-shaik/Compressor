Privacy Policy

Last updated: 28 September 2026

This policy explains what happens to your data when you use this website. It is written to match how the site actually works, not to describe a system we do not have. If you find any statement here that does not match what the code does, please tell us through the contact page.

The short version

  • Your images are processed by your own browser. They are never uploaded to us.
  • We do not store images, filenames, image contents or compressed files.
  • We do not have user accounts and we keep no history of what you compressed.
  • We use Google Analytics for page views and successful compression counts.

How image compression works here

This is a static website. When you choose a file, your browser reads it from your own device using its built-in file API. A JavaScript program in your browser then re-encodes the image using the Canvas API, and the result is handed straight back to you as a download. The work runs in a Web Worker so the page stays responsive, and the PNG encoder uses the browser's own built-in deflate compression. Your image's dimensions change only if you pick a resize limit yourself; nothing is ever resized behind your back.

The page contains no code that transmits your images anywhere. There is no upload endpoint, no server-side image processing, no cloud storage bucket and no third-party image service. Compressing an image never involves a network request carrying the image.

Closing or reloading the page discards everything. Nothing about your images survives in the site, because nothing about your images ever reaches the site.

What is not collected

The site has no backend, so the following never exist and are never written anywhere:

  • Uploaded images or image data of any kind
  • Filenames, file sizes or image dimensions
  • Compressed output files
  • User accounts, sign-ins or authentication data
  • Compression history, saved settings or favourites
  • Analytics does not receive image data, filenames, file sizes, dimensions or compression settings.

Object URLs in your browser

To show previews, the page creates object URLs: temporary links that point at image data held in your own browser memory. They never leave your device and they are not accessible to this site or to anyone else. Each one is released as soon as it is no longer needed, and all of them are released if you navigate away.

Server logs

This site is hosted on GitHub Pages, a static hosting service. Like any web host, GitHub may process standard technical request data such as IP address, user agent and requested URL in order to serve pages and prevent abuse. That processing is governed by the GitHub Privacy Statement, not by us, and it never contains the contents of your images because your images are never sent.

Analytics

We use Google Analytics 4 (measurement ID G-RREK23KDBZ) to count page views and successful image compression operations. Google Analytics may process page URLs, referrers, browser and device information, and online identifiers. Google may process technical information such as IP addresses to provide the service and derive approximate location. Analytics cookies are configured to expire after 24 hours. Google Signals and ad-personalization signals are disabled.

Each successful compression sends a count event without image-specific details. Images, filenames, file sizes, dimensions and compression settings are not sent to Google. Google's handling of analytics information is described in its Privacy Policy. You can block analytics cookies through your browser settings or a content-blocking tool.

Other third-party services

Apart from Google Analytics and the hosting provider described above, this site does not currently integrate social media widgets, font CDNs or third-party libraries.

Children

The service is a general-purpose image utility and is not directed at children. We do not knowingly use analytics to identify children or collect image information.

Your choices

You can block analytics cookies in your browser or with a content-blocking tool. Closing the tab discards the temporary image data held by the page.

Changes to this policy

If the way the site works changes, this policy will be updated in step with the code, and the “last updated” date above will change. Material changes will also be noted on the homepage.

Contact

Questions about this policy can be sent through the contact page.
